= Redmine Issue Extensions Plugin

This is a plugin for Redmine.

This is a fork of planio-gmbh/redmine_issue_extensions 0.2.0, modified by WESEEK to work with Redmine 5.1 or later.

=== Function

1. When the issue is closed, the progress rate is changed to 100% (including bulk edit).
   Nothing is done when the done ratio is calculated from the issue status, or when the done ratio field is disabled for the tracker.

2. When the issue is edited, those who edit it about the issue are added to the watcher of the issue, except when the issue bulk edit.

3. The relating issues can be easily made.

4. When the issue is created and edited, assigned to oneself by clicking [Assigned to oneself] button.

5. The duplicating issues can be easily made.

The following functions of 0.2.0 have been removed.

* Changing the issue status automatically when the assignee is set (Issue Extensions tab in the project settings).
  The table issue_extensions_status_flows and its migration are kept as they are.
* Searching issues by the title when relating issues (use the standard related issue field of Redmine instead).

=== Plugin installation

1. Copy the plugin directory into plugins/redmine_issue_extensions.

2. Migrate plugin: bundle exec rake redmine:plugins:migrate RAILS_ENV=production

3. Start Redmine.

4. Enable the module on the project setting page.

=== Requirements

Redmine 5.1 or higher
