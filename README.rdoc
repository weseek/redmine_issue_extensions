= Redmine Issue Extensions Plugin

これは Redmine の為のプラグインです。

planio-gmbh/redmine_issue_extensions 0.2.0 を元に、Redmine 5.1 以降で動くように WESEEK が改修したものです。

=== 機能

1. チケットクローズ時、自動的に進捗を100%に変更します(一括編集時も含む)。
   進捗率をステータスから算出する設定の場合や、トラッカーで進捗率を無効にしている場合は何もしません。

2. チケット一括編集時を除いて、チケットを更新したユーザをウォッチャーに追加します。

3. 関連するチケットを簡単に作成することが出来ます。

4. チケット作成や更新時、「自分を担当者にする」ボタンクリックで自分自身を担当者に設定することが出来ます。

5. 複製するチケットを簡単に作成することが出来ます。

0.2.0 にあった次の機能は削除しました。

* 担当者を設定したときにステータスを自動的に変更する機能(プロジェクト設定の Issue Extensions タブ)。
  データを保存していたテーブル issue_extensions_status_flows は、migration と共にそのまま残しています。
* 関連付けの際に、題名からチケットを検索する機能(Redmine 標準の関連チケット入力欄で代替できます)。

=== プラグインをインストールする

1. プラグインを plugins/redmine_issue_extensions にコピーします。

2. bundle exec rake redmine:plugins:migrate RAILS_ENV=production を実行します。

3. Redmine を起動させます。

4. プロジェクトの設定ページのモジュールにて、Issue Extensions をチェックし、保存します。

=== 動作環境

Redmine 5.1 以降
